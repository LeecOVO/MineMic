# MineMic 移动版 v0.1.0-ea.1

本次 EA 更新加入可选声音处理、iOS 锁屏控制，并重新设计移动端界面和交互。

## 更新

- 回声抑制：接入 WebRTC AEC3，配合新版 Windows PC 端的扬声器参考音频，减少电脑外放进入手机麦克风产生的回声。
- 降噪：提供通用与桌面游戏场景。桌面游戏场景使用 RNNoise，针对键盘、鼠标及桌面摩擦声，额外算法延迟约 20 ms。
- 收音增强：支持 0–18 dB 调整，方便手机放在桌面或距离较远时使用。
- 所有声音处理默认关闭，可独立选择；参考音频或处理器不可用时自动回退，继续传输麦克风声音。
- iOS 实时活动：可在锁屏和灵动岛查看连接状态，执行静音和断开操作；关闭卡片不停止录音或释放 PC 占用。
- 改进 iOS 音频会话中断、采集停滞及恢复处理。
- 全新图标与浅色／深色界面；配对码、IP 地址支持滑动切换，展开收起、滑条、按钮和电平显示加入连贯反馈。
- 补全键盘退出方式，支持点击空白处、“完成”及切换连接方式时收起键盘。

## 安装与使用

- Android 7.0+：安装 `MineMic-0.1.0-ea.1-android.apk`。本次使用 Release 构建，沿用 EA 测试签名。
- iOS 18.2+：`MineMic-0.1.0-ea.1-ios-unsigned.ipa` 完全无签名，安装前需自行签名；包含实时活动扩展。
- 回声抑制需要 [MineMic-PC v0.1.0-ea.1](https://github.com/LeecOVO/MineMic-PC/releases/tag/v0.1.0-ea.1)，在 PC 选择实际使用的扬声器作为参考设备。单独降噪和收音增强可连接旧版 PC。
- 如需在游戏、会议或录音软件中作为系统麦克风使用，PC 仍需安装独立虚拟声卡。

声音处理可在“声音处理”中展开设置，建议从 +6 dB 增益开始试听。降噪可能影响轻声；实时活动不授予额外后台运行权限，后台录音仍受系统音频会话限制。不同手机、网络及外放设备的效果和稳定性仍需实际使用验证。传输未加密，请在可信局域网使用。

# MineMic Mobile v0.1.0-ea.1

This Early Access update adds optional on-device audio processing, iOS Live Activities, and a redesigned interface.

- Optional WebRTC AEC3 echo cancellation using playback reference audio from the updated Windows PC client.
- General and desktop gaming noise suppression profiles, with RNNoise for keyboard, mouse, and desk noise. The gaming profile adds approximately 20 ms of algorithmic delay.
- Adjustable input gain from 0 to 18 dB. All processing is off by default, with fallback when processing or reference audio is unavailable.
- Optional iOS lock-screen and Dynamic Island status, mute and disconnect controls; improved audio-session interruption and capture recovery handling.
- A new icon, light/dark styling, swipeable connection modes, smooth disclosure animations, refined sliders and level metering, and keyboard dismissal controls.

Android requires 7.0 or later; this Release build retains the EA test signing certificate. The iOS package requires 18.2 or later and is completely unsigned, including its Live Activity extension; sign it before installation. Echo cancellation requires the matching Windows PC release. A separate virtual audio cable is still required to use MineMic as a system microphone.

Live Activities do not grant background execution time. Audio quality, background reliability, and latency depend on the device and network. Use a trusted LAN; transport is not encrypted.
