# MineMic 移动版 v0.1.0-ea.6

本次 EA 更新完善无障碍语义、减少动态效果和大字号排版，包含此前尚未公开发布的 IPv6 连接改进。

## 更新

- 为连接、声音处理、设置、关于、政策、许可、弹窗与实时活动完善读屏名称、状态和操作说明，合并重复内容并隐藏装饰元素。
- 配对码与 IP 输入增加逐字语音标注，保留编辑、粘贴、光标和实际连接操作；配对码模式自动选择 IPv4/IPv6，手动 IP 模式保留两套输入及相应键盘。
- 静音开关使用稳定名称和清晰的声音传输状态；收音增强支持按 1 分贝调整，处理监测使用自然单位，无数据时说明暂无数据，减少重复状态播报。
- 设置中新增“减少动态效果”，默认关闭并自动保存。系统开启时优先遵循系统设置，减少页面移动、按压缩放、展开和箭头旋转，保留必要的状态反馈。
- 大字号下按可用宽度整组调整指标、开关及文字布局，覆盖主页、连接、声音处理、设置和关于页，避免实时数值变化反复改变指标排列。
- 加深浅色和深色主题的输入框边界与未填充滑轨，提高可辨识度；iOS 配对选择器继续使用系统玻璃材质。
- 补齐公开的 iOS Bundle ID、简体中文语言和出口合规声明，签名配置保留在本地；APK 与完全无签名 IPA 均由 GitHub Actions 构建并生成 SHA-256 校验文件。

## 安装与使用

- Android 7.0+：安装 `MineMic-0.1.0-ea.6-android.apk`，使用 EA 测试签名。
- iOS 18.2+：`MineMic-0.1.0-ea.6-ios-unsigned.ipa` 的 App 和实时活动扩展均完全无签名，需自行签名后安装；本附件不是 TestFlight 分发包。
- 构建号 `19`，协议仍为 v2。PC 本次无需更新；IPv6 请使用 [MineMic-PC v0.1.0-ea.8](https://github.com/LeecOVO/MineMic-PC/releases/tag/v0.1.0-ea.8)。
- 在游戏、会议或录音软件中作为系统麦克风使用时，PC 仍需单独安装虚拟声卡，详见 PC 版发布说明。

已完成本地语义及实际操作回调检查、100%/200%/310% 字号排版和减少动态效果回归。实际旁白读法、录音期间旁白可听性、页面焦点恢复及返回手势仍待 iPhone/iPad 验证，本次不声明已完成 VoiceOver 全流程验收。

声音处理仍为可选项，配对、独占、重连和主动断开规则保持兼容。项目继续处于 Early Access，传输未加密，请使用可信局域网。原创代码采用 MIT License，第三方组件遵循各自许可证。

# MineMic Mobile v0.1.0-ea.6

This Early Access update improves accessibility semantics, reduced motion, and larger-text layouts. It also includes the previously unpublished IPv6 connection improvements.

- Add screen-reader names, states and action descriptions across connection, processing, settings, About, policies, licenses, dialogs and Live Activities. Group meaningful content and hide decorative or duplicate elements.
- Add spelling annotations to pairing codes and IP addresses while preserving editing and connection actions. Code pairing automatically discovers IPv4/IPv6; manual input retains separate values and appropriate keyboards.
- Use a stable mute-switch name and accurate transmission state. Adjust input gain in 1 dB steps, describe processing counters in natural units, and reduce duplicate announcements.
- Add a saved Reduce Motion preference, off by default. An enabled system preference takes precedence. Reduce page translation, press scaling, disclosure and arrow motion while retaining meaningful feedback.
- Reflow related controls and metrics together for larger text and narrow screens. Keep metric arrangements stable as live values change, and improve field and slider-track contrast in both themes.
- Correct public iOS bundle identifiers, Simplified Chinese metadata and export-compliance declarations. Keep signing configuration local. Build APK and completely unsigned IPA packages with GitHub Actions and provide SHA-256 checksums.

Android requires 7.0 or later and uses an EA test certificate. iOS requires 18.2 or later; the app and Live Activity extension are completely unsigned and require signing before installation. This IPA is not a TestFlight distribution package. Build: 19. Protocol: v2.

No PC update is required for this release. Use [MineMic-PC v0.1.0-ea.8](https://github.com/LeecOVO/MineMic-PC/releases/tag/v0.1.0-ea.8) for IPv6. A separate virtual audio cable is required for system microphone input.

Local checks cover accessibility semantics and actual action callbacks, 100%/200%/310% text layouts, and reduced-motion behavior. Real-device speech, VoiceOver audibility during recording, focus restoration and escape gestures still require iPhone/iPad validation; this release does not claim complete VoiceOver acceptance.

Audio processing remains optional. Pairing, ownership, reconnection and explicit-disconnect behavior remain compatible. Use a trusted LAN; transport is not encrypted. Original code is MIT-licensed; third-party components retain their licenses.
