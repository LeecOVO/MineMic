# MineMic 移动版 v0.1.0-ea.4

本次 EA 更新加入 IPv6，简化配对流程，并改善连接表单与声音处理监测的交互。

## 更新

- 配对码模式只需输入 6 位数字，自动发现并尝试可用的 IPv4/IPv6 地址；一种地址连接失败后继续尝试其他候选。
- 手动 IP 模式默认 IPv4，可点击或拖动切换到 IPv6；分别保留两套输入，IPv4 使用数字键盘，IPv6 使用完整键盘。
- 支持压缩 IPv6、可选方括号和本机接口作用域；链路本地地址未填写作用域时，自动选择手机 Wi-Fi 接口。恢复凭据支持规范化 IPv6 地址。
- IPv4/IPv6 切换改为扁平的微圆角矩形；提示“输入 IP 直接连接，无需配对码”右对齐，并适配大字体。iOS 沿用无自定义配色的系统玻璃材质。
- 为切换、表单高度和回声处理监测的显示/隐藏补齐动画；新增动画响应系统减少动态效果设置。
- 时钟同步只发送当前会话经过时间，原始手机启动相对时间保留在本机。收到回复后还原本机时钟映射，维持原有回声对齐；同步与采集缓冲配置保持不变。
- 更新 iOS 隐私清单中的系统时间使用理由。

## 安装与使用

- Android 7.0+：安装 `MineMic-0.1.0-ea.4-android.apk`，沿用此前 EA 的测试签名。
- iOS 18.2+：`MineMic-0.1.0-ea.4-ios-unsigned.ipa` 的 App 和实时活动扩展均完全无签名，需自行签名后安装。
- 构建号 `17`，协议 v2。使用 IPv6 请同时更新至 [MineMic-PC v0.1.0-ea.8](https://github.com/LeecOVO/MineMic-PC/releases/tag/v0.1.0-ea.8)；旧 PC 仍可通过 IPv4 使用。
- PC 作为系统麦克风使用时仍需独立安装虚拟声卡，详见 PC 版发布说明。

已完成本地 IPv6 Bonjour 发现、TCP 配对、UDP 音频与外放参考的实际通信验证，以及连接恢复和声音处理回归。不同手机、Windows 网卡、仅 IPv6 网络及锁屏长时运行仍需持续真机测试。本项目继续处于 Early Access。

回声抑制和降噪仍为可选功能。传输未加密，请使用可信局域网。原创代码采用 MIT License，第三方组件遵循各自许可证。

# MineMic Mobile v0.1.0-ea.4

This Early Access update adds IPv6, simplifies pairing, and refines connection controls and processing-monitor transitions.

- Enter only the six-digit pairing code. Discovery automatically tries available IPv4 and IPv6 candidates, continuing when an address cannot be reached.
- Manual IP defaults to IPv4. Tap or drag the compact selector to use IPv6; each family retains its own input. IPv4 uses a numeric keyboard, while IPv6 uses the full keyboard.
- Accept compressed IPv6, optional brackets and local interface scopes. Unscoped link-local addresses use the phone's Wi-Fi interface. Recovery records support normalized IPv6 literals.
- Use a flatter, subtly rounded rectangular selector and right-aligned guidance. Preserve iOS system glass without a custom tint and support larger text.
- Animate selector changes, form height and the echo-processing monitor, respecting system reduced-motion preferences for the new transitions.
- Send only session-elapsed intervals during clock synchronization. Raw phone uptime stays on-device; replies are mapped back to the original local audio clock without changing alignment or buffering settings. Update the corresponding iOS privacy-manifest reason.

Android requires 7.0 or later and retains the previous EA test certificate. iOS requires 18.2 or later; both the app and Live Activity extension in the IPA are completely unsigned and must be signed before installation. Build: 17. Protocol: v2.

Update to [MineMic-PC v0.1.0-ea.8](https://github.com/LeecOVO/MineMic-PC/releases/tag/v0.1.0-ea.8) for IPv6. Older PCs remain usable over IPv4. A separate virtual audio cable is required for use as a system microphone.

Local tests exercised real IPv6 Bonjour discovery, TCP pairing, UDP microphone upload and playback-reference return, alongside reconnection and audio-processing regression tests. Cross-device Windows compatibility, IPv6-only networks and prolonged lock-screen operation still require further device testing. This remains Early Access.

Echo cancellation and noise suppression remain optional. Use a trusted LAN; transport is not encrypted. Original code is MIT-licensed; third-party components retain their own licenses.
