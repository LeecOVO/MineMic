# MineMic 移动版 v0.1.0-ea.2

本次 EA 更新加入可保存的主题设置，并优化音频发送与界面刷新开销。

## 更新

- 新增“设置 → 外观”：跟随系统、白色、黑色。默认随系统夜间模式切换，手动选择立即生效并自动保存。
- 白色主题使用纯白背景，黑色主题使用纯黑背景；统一卡片、文字与控件颜色，保留青绿色强调色。
- 设置页加入进出动画、按压与焦点反馈，支持 Android 返回键；返回连接页后保留配对输入和展开状态。
- 音量表独立刷新，避免整页随电平变化重复重组；iOS 实时活动过滤音量更新，减少主线程任务。
- 复用音频打包缓冲与 Android HMAC 签名对象，减少传输过程中的临时内存分配；保持现有采样率、发送频率与音频处理配置。
- 图标内部圆角方形与声波整体缩小 6%，增加留白，并同步更新 Android、iOS 图标资源。

## 安装与使用

- Android 7.0+：安装 `MineMic-0.1.0-ea.2-android.apk`。使用 Release 构建，沿用上一版 EA 测试签名。
- iOS 18.2+：`MineMic-0.1.0-ea.2-ios-unsigned.ipa` 完全无签名，包含实时活动扩展，安装前需自行签名。
- 构建号为 `7`。协议仍为 v2，配对、独占、重连及主动断开规则保持兼容。
- PC 端继续使用 [MineMic-PC v0.1.0-ea.1](https://github.com/LeecOVO/MineMic-PC/releases/tag/v0.1.0-ea.1)，本次无需更新 PC。
- 在游戏、会议等软件中作为系统麦克风使用时，PC 仍需独立虚拟声卡。

项目继续处于 Early Access 阶段。不同手机、网络环境的耗电、发热、延迟和稳定性仍需实际使用验证。传输未加密，请在可信局域网使用。

# MineMic Mobile v0.1.0-ea.2

This Early Access update adds saved appearance preferences and reduces audio transport and UI update overhead.

- Choose System, White, or Black under Settings → Appearance. System is the default; manual choices apply immediately and are saved.
- Neutral white and black backgrounds, consistent controls and text, and the existing teal accent.
- Animated settings navigation with press and focus feedback, Android back-button support, and retained pairing input and disclosure state.
- Independent audio metering and filtered iOS Live Activity updates reduce unnecessary page recomposition and main-thread work.
- Reused packet buffers and Android HMAC state reduce temporary allocations without changing sample rate, packet cadence, or audio processing settings.
- The inner icon artwork is 6% smaller, with updated Android and iOS launcher assets.

Android requires 7.0 or later. The Release APK retains the previous EA test signing certificate. iOS requires 18.2 or later; the IPA and its Live Activity extension are completely unsigned and must be signed before installation. Build number: 7.

Protocol v2 and connection ownership behavior remain compatible. Continue using MineMic-PC v0.1.0-ea.1; no PC update is required. A separate virtual audio cable is still needed to expose the audio as a system microphone.

This remains an Early Access release. Battery use, thermal behavior, and latency require real-device validation. Use a trusted LAN; transport is not encrypted.
