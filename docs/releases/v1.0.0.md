# MineMic v1.0.0

MineMic 移动端首个正式版本：将 iPhone、iPad 或 Android 手机变成同一局域网内 Windows 电脑的麦克风。

- 支持 6 位配对码发现，以及手动 IPv4 / IPv6 连接。
- 可选降噪、回声抑制、收音增强和 iOS 锁屏实时活动。
- 支持浅色、深色、跟随系统，以及减少动态效果。
- 改进旁白说明和操作：iOS 增益滑块采用原生可调控件，连接方式、地址类型及降噪模式可由旁白选择；补充静音、断开与音频处理条件说明。
- 完善大字号排版、关于、离线隐私说明及 iOS 隐私清单。

构建号 `20`，协议仍为 v2。IPv6 使用 [MineMic-PC v0.1.0-ea.8](https://github.com/LeecOVO/MineMic-PC/releases/tag/v0.1.0-ea.8) 或兼容版本。将声音作为 Windows 录音输入使用时，需另行配置 [VB-CABLE](https://vb-audio.com/Cable/) 等虚拟声卡。音频处理可关闭，效果和延迟受设备、环境与网络影响。

## English

The first public release of the MineMic mobile app turns an iPhone, iPad or Android phone into a microphone for a Windows PC on the same local network.

- Connect with a six-digit pairing code or a manual IPv4 / IPv6 address.
- Optional noise suppression, echo cancellation, input gain and iOS Live Activities.
- Light, dark and system appearance, with a reduced-motion option.
- Improved VoiceOver instructions and native adjustable input gain, accessible connection and processing choices, and larger-text layouts.
- In-app privacy information and iOS privacy manifests.

Build `20`; protocol v2 remains unchanged. Use the compatible PC companion above for IPv6. A separate virtual audio cable is required for system microphone input on Windows.
