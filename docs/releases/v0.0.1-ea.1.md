# MineMic 移动版 v0.0.1-ea.1

MineMic 首个可用的 **Early Access（EA）版本**。让 Android 手机或 iPhone 通过局域网向电脑传输麦克风声音。

## 本次功能

- 支持 Android 和 iOS，提供 APK、IPA 安装包。
- 手机与 PC 在同一局域网，输入 PC 显示的 **6 位配对码**即可连接；也可手动输入 PC 的 IPv4 地址。
- 首台连接的手机独占 PC，其他手机无法抢占；网络中断后保留占用，原手机可自动重连。
- 手机或 PC 主动断开后，释放占用并更新配对码。
- 支持麦克风采集、音量电平显示和静音。
- 修复 iOS 音频成批采集与发送队列不匹配造成的丢帧，减少声音断续及积压。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `MineMic-0.0.1-ea.1-android.apk` | Android 安装包；当前为调试签名的 EA 测试构建 |
| `MineMic-0.0.1-ea.1-ios-unsigned.ipa` | iOS 无签名发布包，不含开发签名和描述文件；安装者需自行签名后安装 |

Android 最低版本为 Android 7.0。iOS 工程部署目标为 iOS 18.2，不同设备和系统版本的兼容性可能存在差异。首次使用请允许麦克风和局域网访问。

## 使用方式

1. 电脑启动 [MineMic-PC](https://github.com/LeecOVO/MineMic-PC)，选择输出设备并开始接收。
2. 手机连接同一局域网，输入配对码，或手动填写 PC 的 IP。
3. 若要在会议、游戏或录音软件中作为系统麦克风使用，PC 需另行安装虚拟声卡，并选择对应的录音端。

## EA 说明

当前基础版本为 `0.0.1`，完整版本为 `0.0.1-ea.1`，仍处于初始开发阶段。不同手机、网络环境、后台/锁屏长时稳定性及量化延迟仍需继续验证。传输尚未加密，请在可信局域网使用。
